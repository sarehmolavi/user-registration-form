# User Registration Form – SimpleFlow

A responsive user registration form built using pure HTML, CSS, and Vanilla JavaScript.
This project includes real-time form validation and follows a Figma-based UI design.

---

## ✨ Features

- Real-time form validation
- Username, full name, email, and password validation
- Secure password rules
- Disabled submit button until all fields are valid
- User-friendly error messages
- Responsive design (mobile & desktop)
- Clean and modern UI

---

## 🛠 Technologies Used

- HTML5
- CSS3 (Flexbox, Media Queries, CSS Variables)
- Vanilla JavaScript (ES6)
